# Animation Improvement Plans

Generated by an `improve-animations` audit on commit `d48bba7`. Each plan is
self-contained (exact file paths, current code, target code, verification
steps) so any executor — human, agent, or cheaper model — can implement it
without additional context.

## Dependencies

- Plan 4 touches `Button.jsx`, which plans 1–2 don't modify — no ordering
  conflict, but do plan 4 after 1–2 so a diff review of the modal/drawer
  fixes isn't muddied by an unrelated `transition-all` sweep in the same pass.
- Plan 5 (duration token) and plan 3 (reduced-motion guard) both touch
  `src/styles/index.css` — apply plan 3 first, then plan 5, to avoid a merge
  conflict in the same file if run by separate executors in parallel.
- Plans 1, 2, 6 are fully independent of each other and of 3–5.
